1. ห้องเรียน ระหว่างคาบ

หน้าแรกที่ผู้สอนเปิดค้างไว้ระหว่างคาบ อัปเดตทุก 1 วินาที

  • แถบบน: ชื่อคาบ เวลาเริ่ม ป้าย "ข้อมูลจำลอง" (เฉพาะคาบจำลอง) และสถานะ CiRA จุดเขียว = กำลังส่งข้อมูล จุดแดง = ถูกปฏิเสธพร้อมเหตุผล
  • ตัวเลขสรุป: เข้าเรียน x/ทั้งหมด · % ตั้งใจเรียนเฉลี่ย 10 วินาที · จำนวนคนหลับ (รวมคนที่ระบุตัวไม่ได้) · คนในภาพ
  • ภาพล่าสุดจาก CiRA: กรอบสีตามพฤติกรรม เขียว = ตั้งใจ, ส้ม = ไม่ตั้งใจ, แดง = หลับ สลับเป็น "กล้องเครื่องนี้" เพื่อเช็คชื่อด้วยเว็บแคมได้
  • รายชื่อ: เวลาเช็คชื่อ สถานะปัจจุบันและนานเท่าไร % ตั้งใจของแต่ละคน กรองได้ ทั้งหมด / มาเรียน / ยังไม่พบ / หลับ

2. ห้องเรียน เมื่อ CiRA แนบภาพ

เมื่อ Python+ node ส่งภาพเฟรมเดียวกันมาด้วย เว็บจะแสดงภาพจริงและวาดกรอบทับ

  • ภาพนี้ส่งด้วย payload ของ DeepDetect ทั้งก้อน (x,y เป็นจุดกึ่งกลาง พร้อม im_w/im_h) ผ่าน cira_bridge.py กรอบตรงกับคนในภาพ
  • ภาพเป็น ภาพสังเคราะห์ สำหรับทดสอบการแสดงผล จึงไม่มีใบหน้าให้จำ เข้าเรียนเป็น 0
  • ภาพเก็บในหน่วยความจำเฉพาะเฟรมล่าสุด ไม่บันทึกลงดิสก์ ปิดคาบแล้วหายทันที
  • กรอบเส้นประสีน้ำเงิน (เมื่อมีใบหน้า) คือใบหน้าที่ระบบตรวจพบ ใช้ผูกพฤติกรรมเข้ากับชื่อนักศึกษา

3. ก่อนเปิดคาบ และลงทะเบียนใบหน้า

4. นักศึกษา

รายชื่อที่ลงทะเบียน ค้นหาด้วยรหัสหรือชื่อ

  • จำนวนภาพใบหน้าที่เก็บ และจำนวนคาบที่เข้าเรียน
  • ปุ่ม "ลบ" ลบภาพใบหน้า ประวัติเช็คชื่อ และพฤติกรรมของคนนั้นทุกคาบ (ถามยืนยันก่อน ย้อนคืนไม่ได้)

5. รายงาน

สรุปย้อนหลังรายคาบ เลือกคาบจากเมนูมุมขวาบน

  • ตัวเลขสรุป: เข้าเรียน · % ตั้งใจเฉลี่ยทั้งคาบ · หลับพร้อมกันสูงสุด · จำนวนเฟรมที่ได้รับ
  • กราฟรายนาที: % ตั้งใจเรียน และจำนวนคนหลับเฉลี่ย (วาดเองด้วย SVG ไม่ใช้ไลบรารีภายนอก)
  • รายบุคคล: แถบสัดส่วนพฤติกรรม นับจากเฟรมที่จับคู่ใบหน้ากับกรอบได้ ไม่ใช่นาทีจริง
  • ปุ่ม "ดาวน์โหลด CSV" ได้ไฟล์ที่เปิดใน Excel ได้ภาษาไทย

6. ตั้งค่า CiRA

ปรับให้ตรงกับโมเดลใน CiRA โดยไม่ต้องแก้โค้ด มีผลกับเฟรมถัดไปทันที

  • การจับคู่คลาส: ชื่อคลาสจาก DeepDetect → ตั้งใจ / ไม่ตั้งใจ / หลับ / ใช้โทรศัพท์ / คน / ไม่นับ คลาสที่ยังไม่จับคู่ขึ้นเป็นปุ่มให้กดเพิ่ม
  • รูปแบบข้อมูล: ค่าเริ่มต้นตรงกับเอกสาร CiRA (x,y จุดกึ่งกลาง, พิกเซล, confidence 0–1)
  • ตรวจการใช้โทรศัพท์: ปิดไว้เป็นค่าเริ่มต้น เพราะกล้องหน้าห้องมักมองไม่เห็น
  • ขวา: endpoint, path ของไฟล์ API key (ไม่แสดงตัวคีย์), โค้ดตัวอย่าง และ payload ล่าสุดที่ CiRA ส่งมาแยกตาม function
